# Складно

Мобильное веб-приложение для совместных покупок без регистрации. Работает как статический сайт на GitHub Pages.

## Возможности

- несколько независимых списков и короткие секретные ссылки только на выбранный список;
- отделы, пакетный импорт из текста и ручное добавление нескольких товаров;
- статусы «нужно купить», «в корзине», «куплено» и массовые действия;
- изменение количества, сверка с текстом чека и добавление цен;
- калькулятор выбранных покупок с делением суммы на людей;
- автоматическая синхронизация между вкладками и устройствами через Firebase Realtime Database.

## Запуск

```bash
pnpm install
pnpm run dev
```

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует `dist` при push в `main`. В настройках репозитория выберите **Pages → Source → GitHub Actions**.

Firebase Realtime Database уже подключена в коде приложения. Для realtime между разными устройствами в правилах базы должен быть разрешён доступ к `/rooms`.
